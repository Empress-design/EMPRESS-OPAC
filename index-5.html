About this catalogue

This is a demonstration catalogue hosted on GitHub Pages. It does not connect to a live Koha database and cannot confirm whether physical copies are held by KSTVET. Before using it as an official catalogue, replace demonstration holdings and call numbers with records verified from the library's own collection.

The “Read online / access page” links open publisher or repository pages for books made available online. Access terms belong to each publisher or rights holder. This site links to those resources; it does not host or redistribute their files.
